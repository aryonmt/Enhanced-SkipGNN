# Contributing

This is a portfolio research repository for Enhanced SkipGNN. Pull requests are welcome for documentation, tests, and bugfixes.

Setup is in the [README](README.md).

Reproducible runs use seeds **42**, **123**, and **7**. GPU paper runs follow the Kaggle protocol. Do not commit paper numbers produced by `--quick`.

Canonical remote: https://github.com/aryonmt/Enhanced-SkipGNN
